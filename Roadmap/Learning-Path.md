# 🗺️ Cloud & Application Security Engineering Roadmap

This document outlines my comprehensive, multi-phase learning path designed to transition my background into a specialized career in **Cloud Security** and **Application Security (AppSec)**.

---

## Phase 1: Foundations & Core Systems
*Establishing a robust baseline in computer architecture, networking, and scripting.*

* **Computer Fundamentals:** Operating systems, Linux CLI navigation, process management.
* **Networking & Web:** TCP/IP model, DNS, DHCP, routing, HTTP/HTTPS request-response lifecycles, and browser behavior.
* **Programming & Automation:** Python scripting fundamentals, version control with Git, and security automation basics.

---

## Phase 2: Information Security & Application Security
*Mastering security governance, threat modeling, and web/API vulnerability mechanics.*

* **Core Principles:** CIA Triad, cryptography basics (symmetric/asymmetric encryption, hashing), and compliance frameworks.
* **Security Tooling & Assessment:** Vulnerability scanning, static analysis (SAST), and threat modeling.
* **Web Application Security (OWASP Top 10):** 
  * Injection flaws (SQLi, Command Injection)
  * Broken Authentication & Session Management
  * Broken Access Control (IDOR, BOLA)
  * Cross-Site Scripting (XSS), CSRF, and SSRF
* **Secure Coding:** Triaging vulnerabilities, fixing insecure code, and container security.

---

## Phase 3: Specialization (Offensive & Cloud Architecture)
*Expanding into enterprise network offense, defensive telemetry, and cloud-native security.*

* **Offensive Security:** Penetration testing methodology, exploitation techniques, and privilege escalation.
* **Defensive Security:** Security Operations Center (SOC) operations, incident response basics, and digital forensics (DFIR).
* **Cloud Security & Infrastructure:**
  * Cloud security architecture & IAM (Least Privilege)
  * Container security (Docker/Kubernetes)
  * Infrastructure as Code (IaC) security
  * Security logging, monitoring, and detection engineering

---

## Phase 4: Advanced Domains & Capstone Execution
*Exploring cutting-edge technologies, specialized domains, and building production-grade security portfolios.*

* **Advanced Topics:** Malware analysis fundamentals, threat intelligence, and understanding Advanced Persistent Threats (APTs).
* **Specialized Security:** Mobile application security (Android/IoT) and industrial control system security.
* **AI & LLM Security:** Securing modern AI applications, mitigating prompt injection risks, and managing tool-use permissions.
* **Portfolio Capstone:** Building out production GitHub projects (Shift-Left DevSecOps Pipeline & AWS Serverless Honeypot).
